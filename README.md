# Tourist Information System

A simple web-based Tourist Information System that helps users find hotels and tourist places using their current location or by searching for a location manually.

## Features

- Find nearby hotels using the user's current location
- Find nearby tourist places using the user's current location
- Search for hotels by entering a location
- Search for tourist places by entering a location
- Google Maps integration for displaying search results
- Responsive design using Bootstrap
- Typing animation on the home page
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Google Maps

## How It Works

The application provides two ways to search for places:

1. **Use My Location**  
   The user can allow location access to find hotels or tourist places near their current location.

2. **Manual Search**  
   The user can enter a location, select either Hotels or Tourist Places, and search for results on Google Maps.

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Allow location access when using the current-location search feature.
